# 🎮 Projeto de Jogo (Em Desenvolvimento)

Este é um projeto pessoal criado com o objetivo de aprendizado em programação.  
O jogo serve como uma base para testar conceitos conforme meu conhecimento evolui.

## 🧠 Objetivo

O principal objetivo deste projeto é praticar:
- Lógica de programação
- Organização e estruturação de código
- Desenvolvimento progressivo de funcionalidades

O projeto não tem como foco se tornar um jogo comercial, mas sim funcionar como um ambiente de testes e evolução.

## ⚙️ Funcionalidades atuais

- Sistema básico de jogo em funcionamento
- Estrutura de código organizada
- Simulação de armazenamento de dados (funciona apenas durante a execução, sem sistema de salvamento permanente)

## 🚀 Tecnologias e ferramentas

- Python
- Git
- GitHub
- VS Code (com integração ao GitHub)

## 🧪 Aprendizados aplicados

Durante o desenvolvimento deste projeto, foram utilizados conceitos como:
- Versionamento de código com Git
- Uso do GitHub para controle de versões e backup do projeto
- Integração do GitHub com o VS Code para commits e gerenciamento do código
- Organização de arquivos e separação de responsabilidades no código
- Lógica de programação aplicada ao desenvolvimento de jogos simples

## 🔄 Em desenvolvimento

- Melhorias na lógica do jogo
- Expansão das funcionalidades
- Possível criação de um frontend para interação do usuário

## 📌 Observações

Este projeto é propositalmente simples e genérico, pois seu foco é o aprendizado contínuo e a experimentação de ideias.
